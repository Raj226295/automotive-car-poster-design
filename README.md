# 🚗 Car Poster Design – Mercedes AMG GT

This project is an automotive poster design inspired by the powerful and stylish **Mercedes-AMG GT**.  
The goal of this design was to create a bold and premium looking poster that highlights the car’s luxury and performance.

## 🎯 Project Goal
- Showcase automotive poster design skills
- Create a clean and modern layout
- Focus on visual hierarchy and composition

## 🛠 Tools Used
- Figma
- Adobe Photoshop

## 🎨 Design Features
- Dark premium background
- Modern poster layout
- High-quality automotive visuals
- Balanced typography and composition
